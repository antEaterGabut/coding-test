# cara instalasi
Intinya harus pake termux di ponsel, kalo di dektop bisa pake power shell ataupun cmd ge cukup
## install dependensi
Install dua tools utama, yakni git untuk mengambil programnya, dan python untuk menjalankannya.

> ingat jalankan ini di termux ya atau di vs code(recomend) kalo punya teks editor lain ya silahkan

cara instalasi sebagai berikut:
''' 

pkg install git python

'''
## konfigurasi awal

'''

git clone https://github.com/antEaterGabut/coding-test

'''

'''
